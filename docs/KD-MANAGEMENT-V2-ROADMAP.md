## Утверждённые решения
- Одна PWA, одна авторизация, рабочие пространства по ролям; собственнику открывать КД Управление.
- Общий дизайн: графит/синий, плитки, KPI, блок отклонений, нижняя навигация, светлая и тёмная темы.
- Замерщик: быстрый расчёт без обязательного клиента и заказа; полный замер объекта отдельно; 2D основной, 3D по кнопке; изделия в мм, участок в м, внутри ядра мм.
- Один набор исходных размеров для сметы, геометрии, чертежей и материалов; расчёт → предложение → договор → заказ.
- Умный помощник: предопределённые запросы/правила, без платного API ИИ.
- Сохранять PHP/MySQL, IndexedDB, PWA, действующие расчётные функции; не менять формулы без эталонов; не подключать платные сервисы без разрешения.
- Серверные права доступа: цены закупки, зарплаты других сотрудников, прибыль не доступны замерщику/клиенту. DEV — только синтетические данные; без подключения к production API.
- Google Таблица остаётся оперативным реестром до согласованной миграции; не дублировать записи. Интеграция Авито отдельно после проверки.

## Правила отчёта
В каждом ответе по разработке: текущий этап N из 11 (порядковый N+1 из 12), процент оставшейся работы по всем 12 этапам, фактически проверенное, блокеры и следующий шаг. Проценты — доля выполненных контрольных пунктов, не затраченного времени. 100% только после проверок. Не перескакивать этапы. Новые идеи отдельно.
