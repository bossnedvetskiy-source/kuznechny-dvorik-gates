# КД Замерщик — Этап 1

Отдельный mobile-first PWA-модуль для выездного замерщика. Не подключён к production `kuzdvor.tw1.ru` и не меняет клиентский сайт.

## Что уже работает

- вход по логину и паролю;
- две роли: `Собственник` и `Замерщик`;
- собственник видит сотрудников, может добавлять, менять роль/пароль и отключать доступ;
- замерщик не видит раздел сотрудников;
- клиенты: имя, телефон, адрес;
- новый замер: клиент, адрес, комментарий;
- в одном замере можно одновременно выбрать `Ворота / калитка`, `Забор`, `Навес`;
- список замеров и карточка замера;
- замерщик не может архивировать заказы, собственник может;
- данные хранятся в IndexedDB на устройстве;
- PWA + Service Worker для запуска без интернета после первого открытия;
- индикатор онлайн/офлайн.

## Тестовые пользователи

- Собственник: `admin` / `1234`
- Замерщик: `zamer` / `1234`

Это только DEV-доступ. Перед реальным использованием авторизацию нужно перенести на сервер и заменить тестовые пароли.

## Модель данных

### Employee
`id`, `name`, `login`, `role`, `active`, `passwordSalt`, `passwordHash`, `createdAt`, `updatedAt`

### Client
`id`, `name`, `phone`, `address`, `createdAt`, `updatedAt`

### Survey
`id`, `number`, `clientId`, snapshot клиента, `address`, `note`, `workTypes[]`, `status`, `createdBy`, `createdAt`, `updatedAt`, `syncState`, `archived`, `schemaVersion`
